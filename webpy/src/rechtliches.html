Datenschutz

Lokale Ausführung

Der eingegebene Python-Code wird mit Pyodide lokal im Browser ausgeführt. Code, Konsolenausgaben und erzeugte Grafiken werden von der Webanwendung nicht an Sebastian Semper oder einen eigenen Anwendungsserver übermittelt.

Hosting und externe Ressourcen

Die Website wird über GitHub Pages bereitgestellt. CodeMirror und Font Awesome werden von cdnjs geladen; Pyodide sowie die wissenschaftlichen Python-Pakete werden von jsDelivr geladen. Beim Abruf erhalten diese Anbieter die technisch üblichen Verbindungsdaten, insbesondere IP-Adresse, Browserinformationen, Zeitpunkt und angeforderte Ressource.

  • Datenschutzerklärung von GitHub
  • Datenschutzhinweise von cdnjs/Cloudflare
  • Datenschutzerklärung von jsDelivr

Die Schriften Inter und Fira Code werden gemeinsam mit dieser Website ausgeliefert; beim Laden der Schriften wird kein externer Schriftdienst kontaktiert.

Keine Analyse oder Konten

Die Webanwendung selbst verwendet keine Analyse- oder Werbedienste, setzt keine Cookies, bietet keine Benutzerkonten an und speichert keine Nutzereingaben dauerhaft. Die Teilen-Funktion schreibt den aktuell gewählten Skriptnamen auf ausdrücklichen Wunsch in die Zwischenablage; der Code selbst ist nicht Teil des Links.
